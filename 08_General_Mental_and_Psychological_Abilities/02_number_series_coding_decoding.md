Series completion and Coding-Decoding test pattern recognition, inductive mathematical intuition, and symbolic processing. Identifying the latent generative rule behind numeric and alphabetic sequences enables quick and accurate problem resolution under strict examination time constraints.


## 1. Taxonomy of Number Series Patterns


### Table: Common Generative Rules in Number Series Problems

| Pattern Type | Underlying Formula / Rule | Illustrative Example | Diagnostic Clue |
| --- | --- | --- | --- |
| Difference of Differences | Successive differences form an AP or prime sequence: $d_2 - d_1 = k$. | 2, 5, 10, 17, 26, ... ($+3, +5, +7, +9$) | Gradual, steady increase between consecutive numbers. |
| Geometric Multiplication / Division | $T_{n} = T_{n-1} 	imes k + c$. | 3, 7, 16, 35, 74, ... ($	imes 2 + 1, 	imes 2 + 2, 	imes 2 + 3$) | Rapid, exponential divergence in values. |

## 2. Alphabetic Positions & Coding-Decoding Strategies

* Forward & Backward Letter Positions: A=1, B=2 ... Z=26. Forward + Reverse Position of any letter always sums to 27 (e.g., A=1, Z=26 -> 1+26=27; M=13, N=14 -> 13+14=27).

* EJOTY Mnemonic: Multiples of 5: E=5, J=10, O=15, T=20, Y=25.

* Opposite Letter Pairs: A-Z (Azad), B-Y (Boy), C-X (Crux), D-W (Dew), E-V (Even), F-U (Full), G-T (GT Road), H-S (High School), I-R (Indian Railways), J-Q (Jungle Queen), K-P (Kurta Pajama), L-O (Love), M-N (Man).

* Fictitious Language / Deciphering Codes: Comparing phrases (e.g., 'pit dar na' = 'you are good' and 'dar tok pa' = 'good and bad') isolates common words and codes systematically by elimination.

### Part B: Screening / Prelims Objective Questions

* Q1. Find the next number in the series: 4, 18, 48, 100, 180, ?
(a) 248
(b) 294
(c) 312
(d) 340
Correct Answer: (b) 294 [Explanation: Notice that: 4 = 1^2 * 4? Alternatively: 4 = 2^2 * 1; 18 = 3^2 * 2; 48 = 4^2 * 3; 100 = 5^2 * 4; 180 = 6^2 * 5. Following this pattern n^2 * (n-1) for n=2,3,4,5,6: the next term is 7^2 * 6 = 49 * 6 = 294.]

* Q2. In a certain code language, 'ROBUST' is coded as 'QNATRS'. How is 'ZYXWVU' coded in that language?
(a) YXWVUT
(b) YXWVTR
(c) AYXWVU
(d) YZWVUT
Correct Answer: (a) YXWVUT [Explanation: In ROBUST -> QNATRS, each letter is shifted by -1 backward in the alphabet: R-1=Q, O-1=N, B-1=A, U-1=T, S-1=R, T-1=S. Applying -1 to ZYXWVU gives Z-1=Y, Y-1=X, X-1=W, W-1=V, V-1=U, U-1=T, resulting in YXWVUT.]

* Q3. If in a code language, 'LEAD' is written as '12514' and 'BOND' is written as '215144', what is the code for 'SAFE'?
(a) 19165
(b) 19156
(c) 19175
(d) 18165
Correct Answer: (a) 19165 [Explanation: Direct positional value of letters: S=19, A=1, F=6, E=5. Concatenated together, this forms 19165.]

* Q4. What comes next in the alternating series: 11, 13, 20, 17, 29, 21, 38, ?
(a) 25
(b) 26
(c) 47
(d) 50
Correct Answer: (a) 25 [Explanation: Split into two interwoven series: Series 1 (odd positions): 11, 20, 29, 38 (adding +9 each step). Series 2 (even positions): 13, 17, 21, ? (adding +4 each step). The missing term is 21 + 4 = 25.]

* Q5. In a coded language: 'tik ja lu' means 'fruits are sweet', 'lu po ma' means 'mangoes are delicious', and 'tik ba po' means 'fruits and mangoes'. Which word stands for 'and'?
(a) tik
(b) lu
(c) po
(d) ba
Correct Answer: (d) ba [Explanation: Compare (1) and (3): common word 'fruits' has common code 'tik'. Compare (2) and (3): common word 'mangoes' has common code 'po'. In (3) 'tik ba po' = 'fruits and mangoes', since 'tik' = fruits and 'po' = mangoes, the remaining code 'ba' must stand for 'and'.]
